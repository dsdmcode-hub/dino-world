#  Dino World

Videojuego de plataformas 2D con desplazamiento lateral, desarrollado como proyecto de aprendizaje utilizando JavaScript, HTML y CSS.

##  Descripción del proyecto

Dino World: Es un videojuego inspirado en los clásicos juegos de plataformas como Mario Bros. El jugador controla a un dinosaurio que debe recorrer escenarios prehistóricos, saltar entre plataformas, superar obstáculos, recoger huevos de dinosaurio y evitar enemigos. 

El objetivo principal es completar los niveles sin perder todas las vidas.

##  Objetivo

Desarrollar un videojuego funcional de plataformas 2D, aplicando los conocimientos adquiridos de JavaScript, HTML y CSS, mientras se aprenden nuevas herramientas, lógica de videojuegos y conceptos de programación durante su desarrollo.
